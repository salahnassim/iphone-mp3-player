# Mon Lecteur

## Où mettre ta musique
Dans l'app **Fichiers** de l'iPhone, crée un dossier "Musique" :
- `Sur mon iPhone > Musique` (local), ou
- `iCloud Drive > Musique` (pense à "Télécharger maintenant" les fichiers).
Au premier lancement, l'app te demande ce dossier. Elle ne copie rien.

## Compiler sans Mac
1. Crée un dépôt GitHub (public = gratuit) et pousse ce dossier.
2. Onglet Actions > "Build IPA" > télécharge l'artefact `MonLecteur-ipa`.
3. Installe le .ipa avec Sideloadly ou AltStore (Windows).
